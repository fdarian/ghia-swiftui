# Drift from syne

Where `ghia-swiftui` behaves differently from `@syne/ui` (`~/code/fdarian/syne/packages/ui`). Names, props and variants are otherwise syne's.

| Component                                        | syne                                                                                                                                             | here                                                                                                                                                                                                                                                                                                                                                                               | cause                                                                                                                                                                                                                                                                                                                                    |
| ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| All                                              | `style?: stylex.StyleXStyles`, merged last so the caller wins                                                                                    | `style?: StyleDesc` (ghia's style object), spread last, so it wins per key                                                                                                                                                                                                                                                                                                         | no StyleX                                                                                                                                                                                                                                                                                                                                |
| All                                              | `render` prop (Base UI `useRender`) swaps the tag or element                                                                                     | dropped                                                                                                                                                                                                                                                                                                                                                                            | no `useRender`; ghia has no tags to swap                                                                                                                                                                                                                                                                                                 |
| All                                              | `data-slot` on every part                                                                                                                        | dropped                                                                                                                                                                                                                                                                                                                                                                            | DOM hook convention, nothing reads it                                                                                                                                                                                                                                                                                                    |
| Tokens                                           | StyleX `defineVars` groups imported from `*.stylex`; dark via `createTheme` classes on `<html>`                                                  | plain objects of getters that read the colour-scheme signal (`ghia-swiftui/tokens/*`); read them in JSX props or effects, never at module scope. Radii, blur and icon sizes are numbers, not `'12px'`                                                                                                                                                                              | no CSS variables; ghia takes numbers                                                                                                                                                                                                                                                                                                     |
| Tokens                                           | alpha ramps by `rgb(from X r g b / n%)`, mixes by `color-mix()`                                                                                  | computed in JS (`tokens/color-math.ts`); seeds and `setAccentColor` must be `#rrggbb`                                                                                                                                                                                                                                                                                              | ghia styles take resolved colours                                                                                                                                                                                                                                                                                                        |
| Colour scheme                                    | `applyColorScheme(isDark)` toggles `.dark` and the theme classes                                                                                 | `applyColorScheme(isDark)` sets the window appearance through the renderer (on macOS the process's `NSApplication.appearance`, so vibrancy and scrollbars flip too); the tokens follow `createAppearance()`. `followSystemColorScheme()` goes back to the OS, the default. The app must render inside `<ColorSchemeProvider>`; a token read outside it throws. No pre-paint script | no `<html>`; appearance is a renderer property                                                                                                                                                                                                                                                                                           |
| Accent                                           | `var(--color-system-accent, themeAccent)` set by the Tauri shell                                                                                 | `colors.accent` is the colour passed to `setAccentColor`, else `themeAccent` (`#138af2` light, `#4fa3f8` dark, syne's own fallback). `setAccentColor(undefined)` clears it                                                                                                                                                                                                         | ghia has no system accent read                                                                                                                                                                                                                                                                                                           |
| Typography                                       | Inter Variable, Geist Mono Variable; per-variant `letter-spacing`                                                                                | system font (`fontFamily` unset, SF), Menlo for the mono variants; letter spacing dropped. Sizes, weights and line heights are syne's                                                                                                                                                                                                                                              | the plan's font decision; ghia has no `letterSpacing` on boxes                                                                                                                                                                                                                                                                           |
| `Text`                                           | a `span`; `as` swaps the tag                                                                                                                     | a `<text>`, which stacks as a block in a block parent (put it in a `<text>`/`<span>` or flex row to flow inline). `as` `h1` to `h4` set `role="heading"` and `aria-level`; `p`, `label`, `pre`, `span` change nothing                                                                                                                                                              | no tags in ghia                                                                                                                                                                                                                                                                                                                          |
| Glass (`Button` `glass`, `GlassPanel`, `Status`) | `-apple-visual-effect` liquid-glass material: system vibrancy, dims children to 40% opacity when the window loses focus, 1px border on macOS 27+ | a neutral tint (`#0000000f` light, `#ffffff12` dark, syne's own blurred-window fallback) plus `backdropFilter: blur(24px)`. No refraction, no vibrancy sample, no dimming on window blur, no macOS 27 border. `bg-glass-sidebar`, `-toast` and `-accent` materials are not ported yet (their consumers land in later slices; `glassAccent` is the accent fill alone)               | ghia has no material choice; it exposes no window focus signal, so there is nothing to dim from (checked: no window `focus`/`blur` event on deactivation, no focus accessor; `setWindowActive` is test-renderer only). `platform.ts` (`startWindowFocusTracking`, `useWindowFocused`, `isMacOS27Plus`) is not ported for the same reason |
| Glass, `Button` `filled`/`muted`                 | `backdrop-filter` blurs only what is inside the element's box                                                                                    | the blur samples past the box edge, so a glass control picks up colour from a neighbour within the blur radius (24px)                                                                                                                                                                                                                                                              | ghia's backdrop filter does not clamp to the element                                                                                                                                                                                                                                                                                     |
| `Button`                                         | 100ms `background-color, color, box-shadow` transition                                                                                           | none; a `type` prop does not exist (no forms)                                                                                                                                                                                                                                                                                                                                      | in ghia 0.11.0 any element with `transition*` loses its `focusVisible` style (box-shadow and outline both), so the focus ring would vanish; the ring is kept, the fade is not                                                                                                                                                            |
| `Button`                                         | a `<button>`                                                                                                                                     | a `div` with `buttonProps` (role button, Tab stop, Enter/Space click), `keyboardFocusDim: false`; takes ghia's `disabled`, `focusableWhenDisabled`, `onClick`                                                                                                                                                                                                                      | no `<button>` in ghia                                                                                                                                                                                                                                                                                                                    |
| Icons                                            | `lucide-react`; `LucideProvider size` sizes the icons among `children` (`Button`, `Badge`, `Status`, `Callout.Icon`)                             | a small local `Icon` (`name` from a fixed set, lucide outlines) and `IconSizeContext`, which the same components provide. An icon with no `size` takes the context size, else 16                                                                                                                                                                                                   | the plan drops lucide; no descendant selectors                                                                                                                                                                                                                                                                                           |
| `Label`                                          | native `<label>`; dims when a sibling or child control is `[disabled]`                                                                           | ghia `<label htmlFor>` (click forwards to the control). Dims only for a disabled descendant (`hasDisabled`), not a following sibling                                                                                                                                                                                                                                               | no sibling selectors                                                                                                                                                                                                                                                                                                                     |
| `Callout`                                        | composed parts recognised by `displayName`                                                                                                       | parts register their element in a `WeakSet`; the root checks its resolved children, so a part wrapped in a `div` or fragment is not seen and the callout stays in its simple, centred layout                                                                                                                                                                                       | host elements carry no component identity                                                                                                                                                                                                                                                                                                |
| `ErrorBoundaryView`                              | `window.location.reload()` on Reload; full-screen via `100vh`; fixed 52px drag strip                                                             | takes an optional `reset` (Solid's `ErrorBoundary` reset) and shows Reload only when it is given; `height: 100%` of its parent; the drag strip is `appRegion: 'drag'`, absolute at the top of the view                                                                                                                                                                             | no page to reload; a fixed strip would cover the window of a demo that shows the view in a pane                                                                                                                                                                                                                                          |
| `ProgressiveBlur`                                | `transform: translateZ(0)`, `-webkit-` prefixed filter and mask                                                                                  | the unprefixed properties only; `height` is a number or string                                                                                                                                                                                                                                                                                                                     | none needed                                                                                                                                                                                                                                                                                                                              |
